# 手作業で測るもの（Google Docs）

ブラウザの UI を手で操作するので、自動化していない。
**入力はすべて `../input/sample.md`。** 他の計測と同じ文書を使う。

結果はこのディレクトリに置く（ファイル名は下記）。スクリーンショットがあると助かる。

---

## Google Docs

**確かめたいこと: 「1本なら Google Docs で十分」がどの程度か。2本目で何が面倒になるか。**

### 手順

1. Google Docs で新規ドキュメントを作る
2. 「編集 → Markdown から貼り付け」で `../input/sample.md` の本文を貼る
   （メニューに無ければ「ツール → 設定 → Markdown を有効にする」）
3. **admonition（注記・警告・危険）を手で作る。** 1セルの表に背景色を付ける、など
4. 目次を入れ、見出しスタイルを整え、ページ番号を入れる
5. 「ファイル → ダウンロード → PDF」→ `google-docs.pdf`
6. かかった時間を測っておく

### 評価表

| | |
|---|---|
| 貼り付けで崩れたもの（表・コード・リスト） | |
| admonition を作るのにかかった時間 | |
| 全体の所要時間（貼り付け〜PDF） | |
| 表の見出し行はページを跨いで繰り返されたか | |
| コードブロックの見た目 | |
| **同じ文書の第2版を作るとしたら、何をもう一度やる必要があるか** | |
| 1本なら十分か（主観） | |

**最後の2行が本題。** 1本目は許容でも、改版のたびに admonition を作り直すなら
それが差別化になる。
